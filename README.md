# Runvista

Plataforma pública para streamers de Pokémon.

Permite gestionar partidas, equipos, capturas,
medallas y overlays sincronizados con OBS.

## Estado

Fase 0: preparación del repositorio y entorno.

## Objetivos

- Gestión multiusuario.
- Partidas Pokémon y desafíos Nuzlocke.
- Equipos, cajas, cementerio y encuentros.
- Editor visual de overlays para OBS.
- Integración con Twitch.
- Colaboración segura.
- Actualizaciones en tiempo real.

## Tecnologías previstas

- TypeScript
- React + Vite
- Tailwind CSS
- Node.js + Fastify
- PostgreSQL + Prisma
- pnpm workspaces
